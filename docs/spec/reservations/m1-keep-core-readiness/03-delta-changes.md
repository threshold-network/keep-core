**Status (2026-09-28; re-verified against `fix/m1-cross-repo-review`): all implementation rows are closed and all 8 test-backfill items are done, including the previously deferred direct validator tests (Story S8; the in-memory EVM harness that closed it landed on `fix/m1-cross-repo-review` — see `../testing-plan.md` §2.5 and the S8 row below).** An earlier draft claimed "all 12 rows below are Done"; the ledger has 11 rows, and the one deferred row was the S8 validator-test row above.
