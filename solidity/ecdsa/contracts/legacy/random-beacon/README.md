# Legacy Beacon support contracts

These seven unmodified source files come from
`@keep-network/random-beacon@2.1.0-dev.18`. Original GPL-3.0-only headers and the
license are retained. Tarball and file hashes are recorded in
`../../../external/random-beacon-export/VENDOR.json`.

They preserve ECDSA's existing interfaces, reimbursement/storage inheritance,
and legacy test helpers without installing the published Beacon package and
its sortition dependency. Changes must be explicit and reviewed alongside
legacy deployment and upgrade compatibility.
